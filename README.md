Entrants write one sentence, at most 280 characters, that brings back a childhood memory. The house judge compares lines in pairs and the most nostalgic one takes the whole $2.

This entry's line is a dial-up memory: the modem screaming its song while Mum yelled from the kitchen not to touch the phone, and a favourite cartoon loading one slow line at a time.

## Run it

```sh
python3 main.py
```
